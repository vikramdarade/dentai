# DentAI Dentist-to-Dentist Referral & Practice Growth Playbook

This playbook details the organic, peer-driven growth loops and communication templates for **DentAI**. In healthcare, software spreads through clinical trust, shared standards, and word of mouth — not aggressive corporate marketing.

---

## 1. The Core Growth Thesis

In dentistry, peer referrals compound through two distinct moments:

```
┌─────────────────┐       ┌────────────────────┐       ┌────────────────────────┐       ┌──────────────────────┐
│  1. Chairside   │  ──►  │  2. Natural Peer   │  ──►  │  3. Friction-Free      │  ──►  │  4. Commercial       │
│     "Wow"       │       │     Trigger        │       │     Artifact           │       │     Conversion       │
│                 │       │                    │       │                        │       │                      │
│ Dentist charts  │       │ Locum covers shift │       │ 1-click Crown Prep     │       │ Practice Owner buys  │
│ 15-min crown in │       │ or peer asks about │       │ template or clinic     │       │ Practice Plan for    │
│ 30 seconds      │       │ recall/CPD note    │       │ code (e.g. SMILE42)    │       │ multi-chair oversight│
└─────────────────┘       └────────────────────┘       └────────────────────────┘       └──────────────────────┘
```

- **The Free Solo Tier is the Distribution Engine:** Individual clinicians, associates, and locums use DentAI freely to eliminate night-time charting.
- **The Procedure Template is the Handshake:** Dentists already debate clinical protocols; sharing a structured Crown Prep or Endo template is an authentic clinical gesture, not a sales pitch.
- **The Practice Tier is the Monetization Engine:** When multiple associates use DentAI in a clinic, the owner upgrades ($99–$149/month per clinic) to unlock centralized multi-chair compliance, immutable APRA/Privacy audit logging, and clinic-wide template governance.

## 2. Channel 1: CPD Events & Study Club Template Sharing

**Context:** Use when discussing complex cases, clinical protocols, or documentation standards with colleagues in WhatsApp groups, study clubs, or dental association meetings.

### WhatsApp / Study Club Message
> "Hey [First Name], after our discussion on crown prep margins and documentation standards, I set up a structured chairside charting template on DentAI that auto-captures the prep details and ADA item codes (611, 615, 627).
>
> You can import the template directly into your chairside setup here:
> 👉 `https://dentai.app/t/crown-prep-sharma`
>
> It listens ambiently during the consult so you don't have to type anything between patients. Let me know what you think of the margin checklist."

**Why it converts:** It provides immediate clinical value (a refined template) rather than asking someone to "try a software product."

## 7. Operational Rules & Etiquette

1. **Protect Professional Trust:** Never use aggressive sales countdowns, artificial urgency, or spam tactics. In dentistry, discretion and clinical accuracy are the brand.
2. **Lead with Clinical Integrity:** Emphasize that DentAI never invents diagnoses or ADA codes. If cloud AI is unreachable, it falls back to a deterministic offline draft that clinicians review.
3. **One Code per Clinic:** Keep the invite code (`SMILE42`) sayable and short. It functions as a clinic access token with owner approvals, keeping join friction at near-zero.
