## Decision Lifecycle Guidelines
- **Status Progression:** `PROPOSED` → `ACCEPTED` → (`SUPERSEDED` or `DEPRECATED`).
- **Never Delete:** Historic records are preserved to ensure complete context traceability.
- When reversing a decision, author a new sequential ADR referencing and superseding the prior record.
